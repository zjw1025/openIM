# openIM demo
vue3 + vite + ts 采用openIM 工具 搭建的前端聊天通讯项目，支持一对一 和多人群组文字聊天 新增群组 查看通讯录 等功能
 openIM 开发文档地址 https://docs.openim.io/zh-Hans/sdks/quickstart/browser（打不开的时候可能需要科学上网）
## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```
